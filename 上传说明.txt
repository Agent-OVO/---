GitHub Pages 上传说明

1. 新建一个 GitHub 仓库。
2. 把本文件夹里的全部内容上传到仓库根目录。
3. 进入 GitHub 仓库 Settings -> Pages。
4. Source 选择 Deploy from a branch。
5. Branch 选择 main / root，然后保存。
6. 等待 1-3 分钟，GitHub 会生成公开链接。

当前包特点
- 已整理为静态网页，可直接用于 GitHub Pages。
- 已包含 .nojekyll。
- 已去掉本地工作目录和 local:// 路径信息。
- 当前标题为“行业研究工作流 | 新型储能研究看板”。
